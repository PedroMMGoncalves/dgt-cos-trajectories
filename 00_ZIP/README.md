- Series 2, COS2018v4 and COS2025v1: https://dados.gov.pt/pt/datasets/carta-de-uso-e-ocupacao-do-solo-cos-serie-2-2018v4-2025v1

(different product: 10 m raster, automatic classification). The tool ignores it anyway.
